Дальнобойная артиллерия Кибран (фан-модель по Supreme Commander 2) -> Mindustry      версия 1.2

МОД (cybran-arsenal.zip)
  Mindustry -> Моды -> Импортировать мод -> Импорт из файла -> выбрать cybran-arsenal.zip -> перезапустить игру.
  Блок появится во вкладке «Турели», исследуется после «Ряби» (Ripple). Размер 3x3. Нужна Mindustry v7 (build 146+).

  Новое в 1.2:
  - Дальность 150 клеток (было 45, x3.3) - бьёт через полкарты. Снаряд летит ~3 с (скорость 5, lifetime 250).
  - Радиус взрыва x1.5 у всех снарядов (графит 7.5 клетки, кинетический сплав 10.5), разрывы крупнее, тряска сильнее.
  - Выглядит как артиллерия: длинный ствол с дульным тормозом, казёнником, катушками и цилиндрами отката (спрайты 224 px).
  - Навесная траектория: снаряд растёт к вершине дуги и уменьшается к падению.
  - scripts/main.js: тень снаряда на земле (уходит в сторону от траектории = видно высоту),
    красная мигающая метка точки падения и свист подлетающего снаряда (cybran-lra-whistle) за ~1.2 с до удара.

  Что есть в игре:
  - Свои звуки (sounds/*.ogg, синтезированы с нуля, без чужих сэмплов):
      cybran-lra-charge  - зарядка ускорителя перед выстрелом (0.7 с)
      cybran-lra-shoot   - выстрел: электро-разряд + удар + лязг затвора + эхо
      cybran-lra-hit     - разрыв фугаса (графит, кремний, взрывчатка)
      cybran-lra-fire    - разрыв зажигательного снаряда (пиратит)
      cybran-lra-emp     - ЭМИ-разряд (кинетический сплав)
      cybran-lra-hum     - тихий гул работающей турели (зацикленный)
      cybran-lra-whistle - свист падающего снаряда (1.25 с, играет скрипт)
  - Анимации спрайтов: бронепластины раскрываются при боевой готовности, ствол откатывается,
    катушки ускорителя накаляются во время зарядки (40 тиков), после выстрела корпус и ствол светятся красным и остывают.
  - Эффекты: сходящиеся искры и кольцо при зарядке, дульная вспышка, дым, вылет гильз,
    красный шлейф снаряда, свои взрывы для каждого типа боеприпаса, тряска экрана.

  Если игра покажет ошибку загрузки мода, откройте content/blocks/cybran-lra.hjson и удалите строку/блок,
  на который ругается игра (наименее проверенные: consumes { coolant ... }, loopSound, chargeSound,
  shoot { firstShotDelay }, часть с suffix "-coil", shrinkX / shrinkY). Затем заново упакуйте zip (mod.hjson должен лежать в корне).
  Если проблемы из-за скрипта (тень/метка/свист) - просто удалите папку scripts/ из мода, турель работает и без неё.

3D-МОДЕЛЬ (model/cybran_lra.glb)
  glTF 2.0, Y вверх, 1 единица = 1 клетка Mindustry. Открывается в Blender, Windows 3D Viewer, онлайн-вьюерах glTF
  (например, gltf-viewer.donmccurdy.com — там можно переключать анимации).
  Иерархия: Base / Turret_Yaw / Turret_Recoil (Body, Wing_L, Wing_R, Barrel_Pitch / Barrel / Charge_Glow).
  Анимации (5 клипов):
      Idle_Scan  6.0 с - турель осматривается влево-вправо (цикл)
      Deploy     1.0 с - бронепластины раздвигаются, ствол поднимается на 42°
      Fire       1.67 с - зарядка катушек (свечение) -> выстрел, откат ствола, толчок корпуса (цикл)
      Undeploy   1.0 с - сворачивание
      Demo_Full  8.4 с - всё подряд: поворот, развёртывание, 2 выстрела, сворачивание
  cybran_lra.obj + .mtl - та же модель в статичной позе (для программ без glTF).
  12 материалов: корпус (3 тона), красная броня Кибран, металл, кабели, вентиляция, катушки, свечение, свечение заряда.

ЗВУКИ (sounds/) - .ogg (для игры) и .wav (для монтажа/других движков), 44.1 кГц.
ВИДЕО (video/) - cybran-lra-ingame.mp4 (со звуком) и .gif: как турель работает в игре.

ИСХОДНИКИ (src/)
  geom.py, model.py           - процедурная геометрия (каждая деталь задана кодом)
  render.py, make_sprites.py  - рендер модели сверху в пиксель-спрайты Mindustry (z-буфер, тени, AO, палитры)
  export3d.py                 - экспорт GLB/OBJ + анимации
  sounds.py                   - синтез всех звуков (numpy)
  video2.py                   - симуляция стрельбы на 150 клеток и сборка ролика (video.py - старая версия)
  whistle.py                  - синтез свиста снаряда
  main.js                     - скрипт мода (тень, метка, свист)
  showcase.py, build_mod.py, poster.py - рендеры, сборка мода, постер
